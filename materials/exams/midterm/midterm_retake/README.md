# 期中考補考

## ⚠️ 補考規則

1. **補考成績取代原成績**
   - 補考分數會直接取代期中考原始成績
   - 無論補考分數高於或低於原成績，都會以補考成績為準

2. **補考後仍可訂正**
   - 補考完成後，仍可繳交「期中考訂正」獲得加分
   - 訂正加分規則與原考試相同（+10 分，滿分以 100 分計）
   - 訂正截止時間：2025/12/10（三）23:59

3. **申請方式**
   - 寄信至 statisticalearning123@gmail.com 申請補考
   - 經老師同意後才會開放作答權限

## TronClass 導入步驟

1. 進入課程 → 線上測驗 → 新增
2. 填寫測驗基本資訊（標題、時間等）
3. 在題目區域點選「匯入」
4. 上傳 `期中考補考_TronClass題庫.xls`
5. 確認 20 題匯入成功
6. 設定防作弊選項
7. 儲存並發布（僅對申請補考的學生開放）
